# Roadmap

Ideas for the next versions. Suggestions are welcome in [Discussions](https://github.com/estatisticomoura/pentakosmos/discussions).

## Art
- Original illustrations for the element cards, the philosophers and the academies, following the theme of the five Platonic solids.

## Translations
- Review of the 38 interface translations by native speakers.
- Rules and creative-process texts in more languages (today: English and Portuguese).

## Computer opponents
- Run the tactical search in a separate thread, so the interface never stalls on slower phones.
- Monte Carlo tree search (MCTS) with sampling of the hidden cards and a time limit per move.
- Longer term: a neural network trained by self-play (reinforcement learning).
- Train against more varied playing styles, including opponents that change course when blocked, as people do.

## Platforms
- Automatic builds for Linux, Windows and Android on every release.
